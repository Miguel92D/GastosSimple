Política de Privacidad

Última actualización: 23 de marzo de 2026

1. Almacenamiento Local

$imple es una aplicación diseñada para funcionar de forma privada. Todos tus datos financieros (ingresos, gastos, metas y deudas) se almacenan exclusivamente de forma local en tu dispositivo. No utilizamos bases de datos en la nube para guardar tus registros financieros.

2. Seguridad de los Datos

No subimos tu información a servidores externos. Tu privacidad está garantizada ya que tú eres el único dueño de tus datos. Al no existir una base de datos centralizada, no hay riesgo de brechas de datos masivas en nuestros sistemas.

Recomendamos realizar copias de seguridad manuales periódicamente utilizando la función de "Backup Local" integrada en los ajustes de la app.

3. Terceros

La aplicación no comparte ningún dato personal ni financiero con terceros. No rastreamos tu comportamiento fuera de la aplicación para fines publicitarios.

Utilizamos Firebase únicamente para funciones básicas de autenticación (si decides usar el inicio de sesión opcional) y analíticas anónimas de errores para mejorar la estabilidad de la app, sin vincularlas a tus movimientos financieros personales.

4. Control del Usuario

Tienes el control total para eliminar todos tus datos en cualquier momento simplemente borrando la aplicación o utilizando la opción de limpieza de datos en los ajustes de tu sistema operativo.
